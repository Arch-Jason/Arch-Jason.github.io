# 无栅格方法

**可以切换本网页的 深色/浅色 模式查看效果**

{% asset_img 1.png %}

从公式的结构来看：
1.  **第一组观测值** ($r_1, g_1, b_1$) 对应的是**白色背景**（背景值为1）。
    公式项 $F_r \alpha + 1 - \alpha$ 等价于 $F_r \alpha + 1 \cdot (1-\alpha)$。
2.  **第二组观测值** ($r_2, g_2, b_2$) 对应的是**黑色背景**（背景值为0）。
    公式项 $F_r \alpha$ 等价于 $F_r \alpha + 0 \cdot (1-\alpha)$。

## 1. 数学推导 (解析解)

为了方便书写，我们对任意颜色通道 $c$ (代表 r, g, b) 进行分析。我们要最小化：
$$ Loss = \sum_{c \in \{r,g,b\}} \left[ (c_1 - (F_c \alpha + 1 - \alpha))^2 + (c_2 - F_c \alpha)^2 \right] $$

**第一步：求解 $\alpha$**

观察两个观测方程的理想状态：
$$ c_1 \approx F_c \alpha + 1 - \alpha $$
$$ c_2 \approx F_c \alpha $$

将两式相减：
$$ c_1 - c_2 \approx (F_c \alpha + 1 - \alpha) - (F_c \alpha) $$
$$ c_1 - c_2 \approx 1 - \alpha $$

这意味着，$1 - \alpha$ 应该等于两张图片像素值的差。为了让三个通道的总误差最小，我们取三个通道差值的**平均值**：

$$ 1 - \alpha = \frac{(r_1 - r_2) + (g_1 - g_2) + (b_1 - b_2)}{3} $$

由此得出 $\alpha$ 的最优解：
$$ \alpha = 1 - \frac{1}{3} \sum_{c \in \{r,g,b\}} (c_1 - c_2) $$

**第二步：求解 $F$ (前景颜色)**

在求出 $\alpha$ 后，我们可以针对每个通道求解最优的 $F_c$。
令 $L_c = (c_1 - F_c \alpha - 1 + \alpha)^2 + (c_2 - F_c \alpha)^2$，对 $F_c$ 求导并令其为 0：

$$ \frac{\partial L_c}{\partial F_c} = -2\alpha(c_1 - F_c \alpha - 1 + \alpha) - 2\alpha(c_2 - F_c \alpha) = 0 $$

假设 $\alpha \neq 0$，消去 $-2\alpha$：
$$ (c_1 - F_c \alpha - 1 + \alpha) + (c_2 - F_c \alpha) = 0 $$
$$ c_1 + c_2 + \alpha - 1 = 2 F_c \alpha $$

得出 $F_c$ 的最优解：
$$ F_c = \frac{c_1 + c_2 + \alpha - 1}{2\alpha} $$

## 代码
```python
import cv2  
import numpy as np  
  
height = 600  
width = 400  
  
img1 = cv2.imread("./1.jpg")  
img2 = cv2.imread("./2.jpg")  
  
img = np.zeros((height, width, 4), dtype=np.uint8)  
  
for i in range(height):  
   for j in range(width):  
       # 归一化n  
       # * 0.5 + 0.5 将第一个照片的亮度提高（始终比第二个亮）+  
       # * 0.5 反之.  
       r1 = min(max(img1[i][j][0] / 255, 1 / 255), 1) * 0.5 + 0.5  
       r2 = min(max(img2[i][j][0] / 255, 1 / 255), 1) * 0.5  
       g1 = min(max(img1[i][j][1] / 255, 1 / 255), 1) * 0.5 + 0.5  
       g2 = min(max(img2[i][j][1] / 255, 1 / 255), 1) * 0.5  
       b1 = min(max(img1[i][j][2] / 255, 1 / 255), 1) * 0.5 + 0.5  
       b2 = min(max(img2[i][j][2] / 255, 1 / 255), 1) * 0.5  
  
       # 最优化的alpha  
       alpha = 1 - 1/3 * (r1 - r2 + g1 - g2 + b1 - b2)  
  
       # 最优化的rgb  
       fr = (r1 + r2 + alpha - 1) / (2 * alpha)  
       fg = (g1 + g2 + alpha - 1) / (2 * alpha)  
       fb = (b1 + b2 + alpha - 1) / (2 * alpha)  
  
       fr = fr * 255  
       fg = fg * 255  
       fb = fb * 255  
       alpha = alpha * 255  
  
       img[i][j] = [fr, fg, fb, alpha]  
  
cv2.imwrite("img-无栅格.png", img)
```

# 栅格法

{% asset_img 2.png %}

## 栅格法图一
1.  **在白背景下**：看起来尽可能像颜色 $(r, g, b)$。
    *   项：$(c - (F_c \alpha + 1 - \alpha))^2$
2.  **在黑背景下**：看起来尽可能像 **黑色 (0, 0, 0)**。
    *   项：$(\alpha F_c)^2$ 其实就是 $(0 - F_c \alpha)^2$。

这意味着你想把一张图片做成**半透明的阴影**，让它在白底上显示原图，在黑底上消失（变全黑）。
### 1. 数学推导

这是一个最优化问题，目标是找到变量 $F$ 和 $\alpha$ 的值，使得损失函数 $loss$ 最小。

给定的损失函数为：
$$ loss = (C - (F \alpha + 1 - \alpha))^2 + (\alpha F)^2 $$

**分析步骤：**

1.  **观察函数结构：**
    该损失函数由两项的平方和组成：
    第一项：$(C - (F \alpha + 1 - \alpha))^2$
    第二项：$(\alpha F)^2$

    由于任何实数的平方都非负（$\ge 0$），因此整个 loss 的最小可能值为 0。
    当且仅当平方和中的每一项都同时等于 0 时，loss 取得最小值 0。

2.  **建立方程组：**
    为了使 loss = 0，我们需要满足以下两个条件：
    $$
    \begin{cases}
    \alpha F = 0 & \text{------ (1) 来自第二项} \\
    C - (F \alpha + 1 - \alpha) = 0 & \text{------ (2) 来自第一项}
    \end{cases}
    $$

3.  **求解方程组：**

    *   **步骤 A：** 将方程 (1) 中的 $\alpha F = 0$ 代入方程 (2)。
        $$ C - (0 + 1 - \alpha) = 0 $$
        $$ C - 1 + \alpha = 0 $$
        解得：
        $$ \alpha = 1 - C $$

    *   **步骤 B：** 将求得的 $\alpha$ 代回方程 (1) 来确定 $F$。
        $$ F \cdot (1 - C) = 0 $$

    此时有两种情况：

    *   **情况 1：$C \neq 1$**
        如果 $1-C$ 不为 0，为了使乘积为 0，必须有 **$F = 0$**。
        此时解为：$F = 0, \alpha = 1 - C$。

    *   **情况 2：$C = 1$**
        如果 $C = 1$，则 $\alpha = 1 - 1 = 0$。
        方程变为 $F \cdot 0 = 0$，这对于任意实数 $F$ 都成立。
        此时解为：$\alpha = 0, F$ 为任意实数。
        *(注：情况 1 中的解 $F=0, \alpha=0$ 也包含在情况 2 中)*

**结论：**

对于通用的常数 $C$，使得 loss 最小（最小值为 0）的最优解是：

$$ F = 0 $$
$$ \alpha = 1 - C $$

此时，
$$ loss_{min} = 0 $$
## 栅格法图二
1.  **第一项**：希望在白色背景（背景=1）下，合成结果接近 **1 (白色)**。
    *   化简内部：$1 - (F\alpha + 1 - \alpha) = \alpha - F\alpha = \alpha(1-F)$。
    *   这表示优化目标倾向于让前景 $F$ 接近 1（白色），或者 $\alpha$ 接近 0。
2.  **第二项**：希望在黑色背景（背景=0）下，合成结果接近 **原图色彩 $c$**。

*   **在白色背景下（如微信日间模式）**：它是白色的（隐形）。
*   **在黑色背景下（如微信夜间模式）**：它显示出原本的图像。
这是一个非约束最优化问题。我们的目标是找到变量 $F$ 和 $\alpha$ 的值，使得 $loss$ 最小。

给定的损失函数为：
$$ loss = (1 - (F \alpha + 1 - \alpha))^2 + (C - \alpha F)^2 $$

### 分析与求解

由于损失函数由两项的平方和组成（形式为 $A^2 + B^2$），该函数的最小可能值为 0（非负性）。
当且仅当两个平方项同时为 0 时，$loss$ 取得最小值 0。

我们要解以下方程组：
$$
\begin{cases}
1 - (F \alpha + 1 - \alpha) = 0 & \text{------ (1)} \\
C - \alpha F = 0 & \text{------ (2)}
\end{cases}
$$

**步骤 1：化简方程 (1)**
$$ 1 - F \alpha - 1 + \alpha = 0 $$
$$ \alpha - F \alpha = 0 $$
$$ \alpha (1 - F) = 0 $$

这给出了两种可能的路径：
*   **路径 A：** $\alpha = 0$
*   **路径 B：** $F = 1$

**步骤 2：结合方程 (2) 进行求解**
方程 (2) 为：$\alpha F = C$

*   **对于路径 A ($\alpha = 0$)：**
    代入方程 (2) 得：$0 \cdot F = C \implies C = 0$。
    这意味着，只有当常数 $C=0$ 时，$\alpha=0$ 才是解（此时 $F$ 可为任意值）。如果 $C \neq 0$，此路径无解。

*   **对于路径 B ($F = 1$)：**
    代入方程 (2) 得：$\alpha \cdot 1 = C \implies \alpha = C$。
    这就得到了一个对任意 $C$ 都成立的解。

**步骤 3：验证解**
将 $F = 1$ 和 $\alpha = C$ 代回原损失函数：
第一项：$(1 - (1 \cdot C + 1 - C))^2 = (1 - (C + 1 - C))^2 = (1 - 1)^2 = 0$
第二项：$(C - C \cdot 1)^2 = (C - C)^2 = 0$
总 Loss：$0 + 0 = 0$。

### 结论

使得 $loss$ 最小（$loss_{min} = 0$）的最优解为：

$$ F = 1 $$
$$ \alpha = C $$
## 代码
```python
import cv2  
import numpy as np  
  
height = 600  
width = 400  
  
img1 = cv2.imread("./1.jpg")  
img2 = cv2.imread("./2.jpg")  
  
img = np.zeros((height, width, 4), dtype=np.uint8)  
  
for i in range(height):  
   for j in range(width):  
       # 归一化n  
       r1 = min(max(img1[i][j][0] / 255, 1 / 255), 1)  
       r2 = min(max(img2[i][j][0] / 255, 1 / 255), 1)  
       g1 = min(max(img1[i][j][1] / 255, 1 / 255), 1)  
       g2 = min(max(img2[i][j][1] / 255, 1 / 255), 1)  
       b1 = min(max(img1[i][j][2] / 255, 1 / 255), 1)  
       b2 = min(max(img2[i][j][2] / 255, 1 / 255), 1)  
  
       # 最优化的alpha  
       alpha1 = min(max(1 - (r1 + g1 + b1) / 3, 1 / 255), 1)  
       alpha2 = min(max((r2 + g2 + b2) / 3, 1 / 255), 1)  
  
       # 最优化的rgb  
       fr1 = (r1 + alpha1 - 1) / (2 * alpha1)  
       fg1 = (g1 + alpha1 - 1) / (2 * alpha1)  
       fb1 = (b1 + alpha1 - 1) / (2 * alpha1)  

       # 逆归一化    
       alpha1 = alpha1 * 255  
       alpha2 = alpha2 * 255
  
       # 栅格选择1或2  
       if (i + j) % 2 == 0:  
           img[i][j] = [0, 0, 0, alpha1]  
       else:  
           img[i][j] = [255, 255, 255, alpha2]  
  
cv2.imwrite("img-栅格.png", img)
```
